# PocketAI

PocketAI is a portable, offline-first local AI environment designed to run from removable storage.

## Current status

- llama.cpp backend
- Qwen3 4B GGUF model
- Local HTTP server
- Linux launcher
- USB-based runtime

## Project layout

- `launcher/` - startup scripts
- `runtime/` - llama.cpp runtime
- `models/` - local model files
- `config/` - PocketAI configuration
- `data/` - runtime data
